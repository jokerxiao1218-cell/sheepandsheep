# 羊了个羊(Pygame 复刻)

2022 年爆火的微信小程序游戏《羊了个羊》的 Python + Pygame 复刻:玩法机制
按原版反编译源码与抓包数据 1:1 还原(见《羊了个羊-设计文档.md》§3.1),
零外部素材(牌面运行时自绘),零网络。

玩法一句话:点牌堆里没被压住的牌,牌进底部 7 格槽,凑满 3 张同图案立即
消除,全部消完过关;槽被 7 张凑不成对的牌塞满就失败。

- **第一关(新手)**:3 种图案 36 张——7 槽鸽巢原理保证一直点就必胜。
- **第二关(原味)**:照真实抓包参数:15 种图案 88 组 264 张、22 层纺锤
  牌堆 + 2 摞盲盒。真随机发牌、不保证有解——原汁原味的地狱难度
  (原版宣传通关率 0.01%)。
- **第二关(可解)**:逆向构造发牌(先模拟一遍通关拿牌顺序、再按消除组
  上图案),构造即证明 100% 存在通关路径。
- 三道具每局各 1 次:**移出**(槽头 3 张暂存,点得回)、**洗牌**(场上
  图案重排,位置不动)、**撤销**(退回最后进槽的一张;发生消除后不可撤)。

## 快速开始

```bash
./run.sh          # 玩(自动用项目自带 venv,屏蔽系统 PYTHONPATH 污染)
./test.sh         # 跑全部 113 个单元测试
env -u PYTHONPATH .venv/bin/python scripts/walkthrough.py
                  # 无头自动对局验收(第一关百局必胜/第二关随机必负/可解回放必胜)
.venv/bin/python scripts/solve.py 2 12345
                  # 问求解器"这一局不用道具有没有解"(限时限节点,不硬撑)
.venv/bin/python scripts/screenshot.py 2 7 classic out.png
                  # 无头渲染截图 + 画面内容占比统计
```

依赖:Python 3.10+、pygame 2.6.1、pytest(项目 `.venv` 已装好;自装用
`pip install pygame pytest`)。中文字体用系统 Noto Sans CJK(Ubuntu:
`sudo apt install fonts-noto-cjk`,缺失会在启动时报错并给出指引)。

## 操作

| 输入 | 作用 |
|---|---|
| 鼠标左键 | 点牌(被压的暗牌点了没反应)/ 按按钮 |
| 顶部 移出 / 洗牌 / 撤销 | 用道具(每局各 1 次,不可用时置灰) |
| Esc | 回主菜单 |
| R | 重开当前关(重新随机发牌) |

牌的三种状态:亮色=可点;灰色=被压住(点不了);看不见=被两个以上
不同层的牌盖住。屏幕下方两摞"盲盒"只有最顶上那张能点,拿下后露出下一张。

## 架构(详见《羊了个羊-设计文档.md》)

```
game/
  data/levels.json   两关参数(照原版地图 JSON 字段命名)
  core/              纯逻辑,零 pygame,可独立单测:
    tiles.py         牌结构、关卡校验、骨架生成(倒生长)、原味发牌
    cover.py         遮挡判定(AABB/三态/点击命中,空间哈希 O(n))
    slot.py          7 槽:聚集插入(同图案挨着)、三消、满判定
    props.py         三道具 + 撤销历史
    game.py          Game 门面——ui/脚本只认它
    solver.py        逆向构造(必可解发牌)+ 回溯求解器(限时限节点)
    tween.py         补间纯函数(lerp/easing)
  assets.py         自绘牌面(15 种"底色+汉字")、中文字体链与自检
  ui.py              场景栈(菜单/游戏/结算)、布局换算、动画
  main.py            入口
scripts/             walkthrough(无头对局验收)/solve(可解性)/screenshot
tests/               113 个 pytest 用例(逻辑全量 + dummy 无头渲染链路)
```

骨架(位置/层)与图案分布是两个独立随机源(skeleton_seed 固定关卡形态、
pattern_seed 每局随机)——这正是原版"服务端下发骨架 + map_seed 随机图案"
的架构。遮挡每次点击后全量重算:264 张牌毫秒级,不维护增量关系网。

## 与原版的已知差异(设计文档 §10)

- 不做"看广告复活":单机版失败直接重开;
- 暗/隐藏牌的精确视觉判定原版未泄露,按社区逆向模型实现;
- 洗牌把 B 区盲盒的图案一起重排(原版是否如此无确证,玩家无感知差异);
- 第一关张数为自定值(原版第一关精确数据无可靠来源)。
